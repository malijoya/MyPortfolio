# MyPortfolio

A modern, highly interactive personal portfolio template built with **React**, **TypeScript**, and **Tailwind CSS v4**.

## Features
- **Ambient Cursor Glow:** Interactive radial gradient tracking mouse position on desktop viewports.
- **Dynamic Dark/Light Mode:** Responsive theme switching synchronized with system preferences and local storage.
- **Scroll Spy Navigation:** Active section highlighting inside the header navbar.
- **Modern Timeline Layouts:** Beautiful timeline styling for Experience and Education milestones.
- **Stateful Project Filters:** Interactive filtering grid allowing projects to be filtered by tags.
- **Simulated Contact Form:** Validation states and submission simulation.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4 (CSS-first engine)
- **Icons:** Lucide React & inline SVGs

## Getting Started

### Prerequisites
Make sure you have Node.js installed on your system.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/malijoya/MyPortfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd MyPortfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally
To start the local development server:
```bash
npm run dev
```

### Production Build
To compile the production assets:
```bash
npm run build
```
The optimized bundle will be generated under the `dist/` directory.
